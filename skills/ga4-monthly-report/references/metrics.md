# Metric definitions
- **Engagement rate** = engaged sessions / sessions. Engaged = lasted >10s, had a key event, or 2+ page views.
- **Conversion rate** = conversions (key events) / sessions.
- **% change** = (current − previous) / previous. Use "n/a" if previous = 0.
- **pp** (percentage points) for differences between two rates.
- **Users**: GA4 de-duplicates users across a period; summing daily rows inflates it. Prefer a month-level export for users.
