# Insight patterns
- Sessions up, conversion rate down → new traffic is less qualified; check which channel grew.
- Organic Search down >15% → check rankings, seasonality, tracking; compare year-over-year.
- Paid traffic up, conversions flat → review targeting/landing pages.
- Direct jumps suddenly → possible tagging/UTM loss; check campaign tagging.
- Engagement rate drops site-wide → check page speed, consent banner, tracking changes.
- Referral spike from one domain → verify it's not spam.
Format: "{Metric} {changed by X%} ({a}→{b}). This is likely because {hypothesis}. Next: {action}."
